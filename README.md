# 프롬프트 위자드 (Prompt Wizard)

직장인 실무에서 바로 쓰는 프롬프트를 골라 만드는 단일 HTML 프로토타입입니다.

- `index.html` — 프롬프트 위자드 프로토타입 (빌드 도구 없이 브라우저에서 바로 실행)
- 오른쪽(모바일은 상단 고정 창)에서 선택값이 자연스러운 완성 문장으로 **실시간 타이핑**되고, 바뀐 문장만 다시 써집니다. 창을 눌러 **직접 수정**하거나 1클릭 복사·챗GPT 열기로 바로 넘길 수 있습니다.
- 모든 동작은 브라우저 안에서만 이루어지며, 입력한 내용이 서버로 전송되지 않습니다.
- 글꼴은 Google Fonts(Noto Sans KR)를 불러옵니다.

## 사용

GitHub Pages: https://elcue2-cpu.github.io/prompt-wizard/

로컬에서는 `index.html`을 브라우저로 열면 됩니다.
