# Prompt Wizard

공공기관·공무원 8대 분야 62개 업무의 실무 프롬프트를 4단계 질문(분야 → 업무 → 결과물 → 조건)으로 조립하는 정적 웹앱입니다.
빌드 도구 없이 `index.html`을 열면 바로 동작합니다(로컬 `file://` 포함).

- 서비스: https://elcue2-cpu.github.io/Prompt-wizard/ (대문자 `P`)
- 태그: `v3-final`(v3 기준점), `v4.0`(4직무 23업무), `v4.1`(8분야 62업무·216 템플릿 카드·자연어 검색), `v4.2`(순차 위자드·소속 기관·느린 타이핑), `v4.3`(1단계부터 실시간 프롬프트·빠른 시작 제거·수동 단계 이동·모바일 세로 배치)

## 지금 되는 것 (v4.3)

- **상위 카테고리 5개** — `공공기관·공무원`(live) / `일반기업·회사원` · `자영업·소상공인` · `대학생·취준생` · `일상·생활·재테크`(준비 중). 준비 중 탭에는 `준비 중` 배지가 붙고, 누르면 **화면 전환 없이** 가운데 모달(`role="dialog"`·`aria-modal`)로 카테고리 이름·아이콘·“🚧 준비 중인 카테고리예요”·예정 기능 3줄·`[확인]`을 보여 줍니다. 이때 현재 카테고리·위자드 선택·에디터 내용은 그대로입니다(배경 클릭·ESC·✕로 닫기)
- **자연어 업무 검색(API 호출 0)** — STEP 01 상단 검색창에 “전기실 정기점검 결과보고서”처럼 쓰면 분야›업무›결과물을 바로 추천하고, 누르면 그 업무로 이동합니다(정규화·동의어·가점 점수식, 회귀 20문항 고정)
- **8대 분야 · 62업무** — 사무·행정 / 인사·재무 / 기획·PM / IT·보안 / 기술 / 시설 / 현장 / 안전. 분야별 전문가 사고 프레임(판단 5단계·필수 질문 4~5개·검증 5기준·문체)이 질문과 검증을 바꿉니다
- **1단계부터 시작되는 실시간 프롬프트(v4.3)** — 결과물이나 「빠른 시작」을 누르지 않아도, STEP 01에서 **소속이나 분야를 고르는 순간** 오른쪽에 역할 문단이 써지기 시작합니다. 업무를 고르면 맥락·분야 프레임이, 결과물을 고르면 요청·형식·문체·검증이, 조건·메모를 채우면 조건·상황·유의사항이 이어 붙습니다. 아무것도 고르지 않았을 때만 빈 상태입니다
- **순차 위자드 + 수동 이동(v4.3)** — 한 번에 한 단계만 보이고, **선택해도 자동으로 넘어가지 않습니다**. 아래 `[← 이전 단계]` `[다음 단계 →]` 버튼과 상단 진행 레일(잠금 해제된 단계)로 직접 이동하므로, 고른 직후 오른쪽에서 문장이 다듬어지는 걸 보며 다음 선택을 이어 갈 수 있습니다. 앞 단계로 돌아가 고쳐도 선택값은 그대로 남습니다(검색 결과·URL 프리셋만 해당 단계로 바로 이동)
- **모바일 세로 배치(v4.3)** — 작은 화면에서는 위에 심플한 질의응답 카드, 바로 아래에 실시간 프롬프트 창(복사·챗GPT 버튼 포함)이 이어집니다. 하단 고정 바와 `전체 보기` 시트는 없앴습니다
- **소속 기관 성격·기관명(v4.2, 선택)** — STEP 01에서 `공단·공사` / `중앙부처·지자체` / `출연연·교육기관` / `기타 공공기관` 중 하나를 고르고 기관명을 적으면, 역할·맥락 문단이 `○○공단(공단·공사)의 … 담당자`처럼 채워집니다. 비워 두면 기존 문장과 완전히 같습니다
- **3단계 위자드** — STEP 01 분야(8장) → STEP 02 세부 업무(6~9개) → STEP 03 업무 전용 특화 템플릿 카드(3~4장) + 공통 결과물 7종 → STEP 04 분야 공통 조건 + 문서 조건 + 메모 + 가드레일
- **특화 템플릿 216장(고유 정의 164종)** — 점검표·대장·일지·공문·보고서·품질검토. 카드를 고르면 상속 결과물·미리 채운 칩(preset)이 화면에 보이고 전용 질문 1개가 붙습니다
- **7번째 결과물 `표·서식`** — 점검표·일지·대장은 수식 문장 대신 표 머리글·기재 요령·서명란으로 조립합니다
- **공통 조립 엔진** — 역할·맥락·요청·분야 프레임·상황·형식·문체·규칙·조건·관점·분량·유의사항·검증 13문단(프레임·조건은 해당할 때만)
- **하위 호환 별칭** — `?job=ops&task=bsc` 같은 구 URL·즐겨찾기·최근 기록을 `biz/performance`로 풀어 열고, 주소창은 새 id로 되씁니다(localStorage `schema=2` 마이그레이션)
- **v3 에디터 그대로** — 실시간 타이핑(28ms×55프레임≈1.5초), 바뀐 문단 하이라이트, 커서, 직접 수정 보호(선택이 바뀌었어요 · ↻ 자동 생성 반영), 1클릭 복사, 챗GPT 열기(긴 프롬프트는 복사 후 이동), 후속 팁
- **공문 갑지 분기 유지** — `타 부서·대외 협조공문`만 갑지, 감사·의회·계약은 개조식
- **품질 점검(AI 호출 0)** — 역할 지정·상황 설명·목적 명확성·출력 형식·제약 조건 5지표 × 20점. 부족한 항목마다 무엇을 채우면 되는지 안내
- **즐겨찾기·최근(localStorage)** — 최근은 선택값만 최대 10건(본문·메모 미저장), 즐겨찾기는 사용자가 저장한 제목·본문만. 저장소가 막히면 조용히 숨김
- **URL 프리셋** — `?cat=&job=&task=&out=&opt=`, 첫 렌더 전에 적용(이중 타이핑 없음). 데스크톱에서는 선택 상태를 주소창에 되씁니다
- **SEO 랜딩 6종** — `landing/*.html`, 각 페이지 고유 title·description·canonical·OG·FAQ JSON-LD + 위자드 CTA
- **수익화 기반** — `assets/js/data/config.js`의 `ads.enabled:false`. 승인 전에는 광고 스크립트·슬롯 요청이 0건입니다

랜딩 문구를 고칠 때는 `tools/build_landing.py`의 `PAGES` 표를 고치고 `python3 tools/build_landing.py`를 다시 돌립니다.
